DSR Tracker – WICHTIG / BITTE LESEN
====================================

Was ist das?
------------
Der DSR Tracker zeigt im Stream (OBS) an, welche Bosse und Minibosse aus der
Punkteliste in Dark Souls Remastered besiegt sind, und rechnet die Punkte
zusammen. Dazu gibt es eine Steuerseite im Browser und einen Guide.

Projektseite: https://github.com/spidy666/DSRtracker


Drei Wege
---------
A) Fertige exe (am einfachsten)
   Von der Release-Seite laden: https://github.com/spidy666/DSRtracker/releases
   Die exe wird dort von GitHub öffentlich aus dem Quellcode gebaut und mit
   Prüfsumme und signiertem Herkunftsnachweis veröffentlicht. Wie du das
   prüfst, steht in der README unter "Download und Prüfung".
   Später aktualisieren: update.bat doppelklicken.

B) Selbst bauen (wenn du niemandem vertrauen willst)
   Siehe "So geht's" unten – die exe entsteht aus genau dem Code, den du liest.

C) Web-Version ohne exe (nichts installieren, Abhaken von Hand)
   https://spidy666.github.io/DSRtracker/  – läuft komplett in OBS.
   Anleitung für einen eigenen Webserver: docs\WEBVERSION.md


So geht's (selbst bauen)
------------------------
1. Quellcode herunterladen (GitHub: "Code" -> "Download ZIP") und entpacken.
2. Code ansehen (optional, aber dafür ist es gedacht):
   Das Programm besteht aus vier C#-Dateien mit ca. 1.400 Zeilen
   (Program.cs, GameReader.cs, Tracker.cs, WebServer.cs), ausführlich
   kommentiert. Eine Erklärung aller Teile steht in docs\CODE.md.
3. Das .NET SDK installieren (kostenlos, von Microsoft):
   https://dotnet.microsoft.com/download/dotnet/8.0   -> "SDK x64"
4. build.bat doppelklicken.
   Danach liegt die fertige DSRTracker.exe im Ordner "dist".
5. DSRTracker.exe starten (vor oder nach dem Spiel).
   Beim ersten Start öffnet sich der Einrichtungsassistent im Browser,
   danach die Steuerseite: http://localhost:8765/
6. In OBS: Quelle hinzufügen -> Browser -> URL von der Steuerseite einfügen
   (z. B. http://localhost:8765/overlay?view=compact).


Worauf du beim Prüfen achten kannst
-----------------------------------
- NUR LESEN:
  In GameReader.cs wird das Spiel ausschließlich mit Leserechten geöffnet
  (PROCESS_VM_READ | PROCESS_QUERY_LIMITED_INFORMATION) und es wird nur
  ReadProcessMemory verwendet. Administratorrechte braucht das Programm nicht.
  WriteProcessMemory kommt im gesamten Code nicht vor.
  -> Das Programm verändert nichts am Spiel und nichts am Spielstand.

- KEIN INTERNET:
  Der Webserver in WebServer.cs lauscht nur auf "localhost" und nimmt
  nur Anfragen vom eigenen Rechner an. Andere Webseiten im Browser können
  den Stand weder lesen noch verändern (Host-, Origin-Prüfung, kein CORS).
  Das Programm baut keine Verbindungen ins Internet auf. Auch die
  Schriftarten werden lokal mitgeliefert (Ordner web\fonts).
  Nur update.bat verbindet sich mit GitHub – und nur, wenn du es startest.

- DATEIEN:
  Das Programm schreibt nur in %APPDATA%\DSRTracker:
  state.json (manuelle Haken, letzte Kills, Einstellungen).
  Mit der Startoption --portable stattdessen in den eigenen Ordner.

Hinweis
-------
Gegner, die im Spiel respawnen (z. B. die Black Knights im Ofen der Ersten
Flamme), haben kein dauerhaftes Kill-Flag. Die werden auf der Steuerseite per
Klick abgehakt. Alles andere erkennt das Programm automatisch.
