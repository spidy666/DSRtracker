DSR Tracker – Web-Version

Das Overlay für Dark Souls Remastered, ohne exe: läuft komplett in OBS, Gegner werden von Hand abgehakt. Wer automatische Erkennung möchte, nimmt die exe aus dem Hauptprojekt.

Nichts zu installieren, keine Anmeldung. Der Stand (Haken, Uhr) bleibt im Speicher von OBS bzw. des Browsers und wird nirgendwohin gesendet.

Einrichten in OBS

  1. Steuerung als Dock: OBS → Docks → Benutzerdefinierte Browser-Docks. Name „DSR Tracker“, URL:
  2. Overlay anpassen: Im Dock (rechte Spalte, „OBS-Overlay“) Ansicht, Farben usw. wählen und URL kopieren.
  3. Overlay einfügen: In der Szene Quelle hinzufügen → Browser, die kopierte URL einfügen, Größe wie im Dock angegeben.
  4. Spielen: Gegner im Dock anklicken = abgehakt. Das Overlay aktualisiert sich sofort. Die Run-Uhr im Dock starten, wenn Zeit und Punkte pro Stunde angezeigt werden sollen.

Wichtig: Dock und Overlays müssen von derselben Adresse kommen (alles von hier). Zum Ausprobieren ohne OBS: Steuerung und ein Overlay in zwei Browser-Tabs öffnen.

Unterschiede zur exe

  • Keine automatische Erkennung – alles wird von Hand abgehakt.
  • Statt der Spielzeit gibt es eine Run-Uhr zum Starten und Pausieren.
  • „Aktuelles Gebiet“ wird von Hand eingestellt.
  • Stand sichern/laden als Datei, z. B. für einen anderen PC.
